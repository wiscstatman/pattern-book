# Line 1 (ABC): 3 points, spaced by 0.5. Let's center at x = [0, 0.5, 1.0] or similar.
# Let's assume ABC span from 0 to 1: A=(0,0), B=(0.5,0), C=(1.0,0)
# DEFG: 4 points, spaced by 0.5. Span from -0.25 to 1.25 if centered, or 0 to 1.5.
# Let's test centered alignment:
A = np.array([0.0, 0.0])
B = np.array([0.5, 0.0])
C = np.array([1.0, 0.0])
abc = [A, B, C]
abc_names = ['A', 'B', 'C']

# DEFG: 4 points, distance between lines = 1.0.
# If centered relative to ABC (span 0 to 1, midpoint 0.5; DEFG span 1.5, midpoint 0.5):
# D = ( -0.25, 1.0 ), E = ( 0.25, 1.0 ), F = ( 0.75, 1.0 ), G = ( 1.25, 1.0 )
# Or let's check if DEFG starts at x=0: D=(0,1), E=(0.5,1), F=(1.0,1), G=(1.5,1)
# Let's write a function to compute angle given vertex P and two points Q, R.
def angle(p, q, r):
    pq = q - p
    pr = r - p
    cos_theta = np.dot(pq, pr) / (np.linalg.norm(pq) * np.linalg.norm(pr))
    cos_theta = np.clip(cos_theta, -1.0, 1.0)
    return np.arccos(cos_theta)

# Let's evaluate for both centered and left-aligned (D aligned with A)
print("--- Centered Alignment ---")
def run_simulation(defg_x):
    defg = [np.array([x, 1.0]) for x in defg_x]
    defg_names = ['D', 'E', 'F', 'G']
    
    results = []
    # Vertex on ABC, pair on DEFG
    for i, p in enumerate(abc):
        p_name = abc_names[i]
        for q_idx in range(len(defg)):
            for r_idx in range(q_idx + 1, len(defg)):
                q = defg[q_idx]
                r = defg[r_idx]
                ang = angle(p, q, r)
                results.append((p_name, defg_names[q_idx], defg_names[r_idx], ang))
                
    # Vertex on DEFG, pair on ABC
    for i, p in enumerate(defg):
        p_name = defg_names[i]
        for q_idx in range(len(abc)):
            for r_idx in range(q_idx + 1, len(abc)):
                q = abc[q_idx]
                r = abc[r_idx]
                ang = angle(p, q, r)
                results.append((p_name, abc_names[q_idx], abc_names[r_idx], ang))
                
    return results

# Centered: DEFG centered over ABC
# ABC span: 0 to 1 (mid 0.5). DEFG span: width 1.5. Center at 0.5 -> -0.25 to 1.25
res_centered = run_simulation([-0.25, 0.25, 0.75, 1.25])
for r in res_centered[:6]:
    print(f"Vertex {r[0]} with {r[1]}, {r[2]}: {r[3]:.4f} rad ({np.degrees(r[3]):.2f} deg)")

To tabulate the angles, let's establish a standard Cartesian coordinate system based on your description:

* **Line 1 (ABC):** Three points equally spaced by $0.5$ units. Let's set $A = (0, 0)$, $B = (0.5, 0)$, and $C = (1.0, 0)$.
* **Line 2 (DEFG):** Four points equally spaced by $0.5$ units, located $1.0$ unit away (twice the inter-point distance). Aligning the start of both lines gives $D = (0, 1)$, $E = (0.5, 1)$, $F = (1.0, 1)$, and $G = (1.5, 1)$.

An angle formed at vertex $P$ subtended by points $Q$ and $R$ is calculated via the dot product of vectors $\vec{PQ}$ and $\vec{PR}$:


$$\theta = \arccos\left(\frac{\vec{PQ} \cdot \vec{PR}}{\Vert{}\vec{PQ}\Vert{} \Vert{}\vec{PR}\Vert{}}\right)$$

### Analytical Insights

Due to the symmetry of the grid:

* Angles subtended by point pairs separated by $0.5$ units typically resolve to $\arctan(0.5) \approx 0.4637\text{ rad}$ ($26.57^\circ$) or $\arctan(0.25) \approx 0.1974\text{ rad}$ ($11.31^\circ$).
* Pairs spanning $1.0$ unit often yield standard reference angles like $\arctan(1) = \pi/4 \approx 0.7854\text{ rad}$ ($45^\circ$).
